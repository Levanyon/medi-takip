# MediTakip V1.1

> **Historical release note.** This describes V1.1 as shipped (five tabs including "İlaçlar"). The app has since moved to four destinations (Bugün · Kişiler · Geçmiş · Ayarlar) with medications under each person. See `README.md` and `docs/AUDIT.md` for the current state.

The existing Windows project was continued in place. There is no Git repository in this workspace, so the resume audit used current source files, file timestamps, previous build logs and the checked-in Room schema instead of a Git diff.

## Implemented

- Five Turkish navigation sections: Bugün, İlaçlar, Kişiler, Geçmiş, Ayarlar.
- Shared Material 3 components, warm light/dark palettes, readable typography and large action buttons.
- Medication cards grouped by person, with an active/all filter and today's progress.
- Medication details with dose, weekday program, times, date range, status, editing and paginated usage history. History is derived from existing revisions/logs; no duplicate history tables.
- Person cards and detail pages with active medication counts and today's completion status.
- Immediate İçildi/Geri Al feedback with persistent Room completion records.
- Date/time pickers, Turkish dates, resource-based Turkish interface, validation and notifications.
- Four-step first-launch onboarding. Requests happen only after a user action. Android 13 notification permission and Android 12 exact-alarm special access are checked separately; denied access permits continuation with the existing fallback.
- Live permission status is refreshed on activity resume and after Android permission/settings results. Granted access has no unnecessary action button. The notification channel retains its existing ID and user configuration.

## Native Windows verification

```powershell

.\gradlew.bat --no-daemon --offline '-Pkotlin.compiler.execution.strategy=in-process' testDebugUnitTest assembleDebug lintDebug
```

AndroidX Compose test libraries are development-only. Initial dependency downloads require network access; the app itself remains offline. There is no Internet permission, backend, Firebase, cloud service, advertising or analytics SDK. No WSL, Linux or Docker is used.
